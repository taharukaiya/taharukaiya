# Rukaiya Taha - Developer Portfolio

A sleek, modern, and high-performance developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion. 

![Portfolio Preview](./portfolio_hero_mockup_1790953674311.jpg)

## 🚀 Features

- **Modern Glassmorphism UI:** Built with sleek frosted glass effects and a deep space/dark navy theme.
- **Performant Animations:** Smooth scrolling, page reveals, and interactions powered by Framer Motion.
- **Canvas Particle Network:** A lightweight, custom-built animated background in the hero section.
- **Dynamic Projects Showcase:** Easily managed and categorized project displays (Full-Stack, Blockchain, AI, etc.).
- **Timeline Components:** Animated components for Education and Work Experience.
- **Customization Ready:** All content is managed centrally through a single data file (`src/data/portfolioData.js`).
- **Fully Responsive:** Beautifully crafted for mobile, tablet, and desktop experiences.

## 🛠️ Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, react-type-animation
- **Icons:** React Icons
- **Deployment:** Ready for Vercel / Netlify / GitHub Pages

## 📦 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/taharukaiya/taharukaiya.git
   ```
2. Navigate to the project directory:
   ```bash
   cd taharukaiya
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 📝 Configuration

To update the portfolio with your latest details, simply edit the `src/data/portfolioData.js` file. The entire application pulls data (bio, skills, projects, experience, publications) from this single source of truth.
